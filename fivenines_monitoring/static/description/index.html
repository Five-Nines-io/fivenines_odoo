Fivenines Monitoring

The Odoo.sh "Monitor" tab, for every Odoo you run

Install the module, paste your Fivenines enrollment key, done. Every minute, each Odoo instance pushes its own metrics to Fivenines over HTTPS. Nothing to open on the firewall, no agent to run. Odoo 16, 17, 18 and 19, Community and Enterprise, Odoo.sh and self-hosted.

  • Requests: requests per minute by status, p50 / p95 / p99 latency, SQL per request.
  • Errors: ERROR and CRITICAL counts grouped by fingerprint, without customer data.
  • Scheduled actions: late, stuck, running and failing crons.
  • Database: size, connections, longest transaction.
  • System: CPU, memory, disk, with real container limits (cgroup v1/v2).
  • Restarts: redeploys show as events, not as gaps.

Each instance gets its own secret, revocable on its own. Copied databases (staging from production) enroll as new instances automatically. Secrets are never logged.
